# 🌤️ Application Météo

Une application web simple et élégante pour consulter la météo, construite avec HTML, CSS et JavaScript.

## 📋 Table des Matières
- [Fonctionnalités](#fonctionnalités)
- [Technologies](#technologies)
- [Installation](#installation)
- [Utilisation](#utilisation)
- [Structure du Projet](#structure-du-projet)

## ✨ Fonctionnalités
- Affichage de la météo actuelle.
- Interface utilisateur moderne.
- Design soigné avec CSS personnalisé.

## 🛠️ Technologies
- **HTML5** : Structure sémantique de la page.
- **CSS3** : Mise en forme et design (fichier `style.css`).
- **JavaScript** : Logique de l'application (fichier `script.js`).

## 🚀 Installation

1. Clonez ce dépôt ou téléchargez les fichiers.
2. Assurez-vous d'avoir les fichiers suivants dans le même dossier :
   - `main.html`
   - `style.css`
   - `script.js`

## 📖 Utilisation

Double-cliquez simplement sur le fichier `main.html` pour lancer l'application dans votre navigateur web préféré.

## 📂 Structure du Projet

```
/
├── main.html      # Page principale de l'application
├── style.css      # Feuille de styles
├── script.js      # Script pour la logique météo
└── README.md      # Documentation du projet
```
